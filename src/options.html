GitHub Merge Helper

Claude API

Requests go through a small native helper that keeps your API key in the macOS Keychain (or the Linux keyring), outside the browser. To install it, or to change the key, run this from the extension's source directory and restart Firefox:

python3 native/install.py           # first time
python3 native/install.py --set-key # change the key

Only needed for private repositories or if you hit the unauthenticated rate limit (60 requests/hour). Use a fine-grained token with read-only “Pull requests” and “Contents” access and nothing else. It's only sent to api.github.com.

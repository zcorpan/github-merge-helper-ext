# Security policy

Please report security issues privately, using GitHub's [private vulnerability reporting](https://github.com/zcorpan/github-merge-helper-ext/security/advisories/new), and not in a public issue or pull request.

The "Security" section of [README.md](README.md) describes the threat model: PR data is untrusted and may contain prompt injection, and the properties the extension is meant to hold despite that.

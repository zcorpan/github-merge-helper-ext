# Building

The add-on package is `dist/`, generated by [`build.mjs`](build.mjs). It bundles each entry point in `src/` (`background.js`, `content.js`, `redirect.js`, `options.js`) with its imports from `src/` into one file using [esbuild](https://esbuild.github.io/) (not minified), and copies `manifest.json`, `src/content.css`, `src/icon.svg`, `src/options.html` and `src/options.css`. All code is in this repository and no third-party code is bundled. esbuild is the only build dependency; its version is pinned in `package-lock.json`.

## Environment

Built on macOS (Apple silicon) with Node 24.11.0 and npm 11.21.0. The build doesn't depend on the OS, so Ubuntu 24.04 ARM64 with Node 24 and npm 11 should give the same output.

## Commands

```sh
npm ci
npm run build    # writes dist/
```

To compare with a submitted version, unzip its `.xpi` into a directory and run `diff -r dist <that directory>`. Only `META-INF/`, which AMO's signing adds, should differ.

## Not part of the add-on

`native/` is a separate local program (the native messaging host) that users install from a checkout with `python3 native/install.py`. It isn't in the package. `test/`, `scripts/`, `amo/` and the docs aren't in the package either.
